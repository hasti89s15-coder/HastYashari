پروژه‌ی سایت تولد یاشار — نسخه‌ی شروع

ساختار:
index.html                  صفحه‌ی اصلی و ورودی احساسی
assets/css/style.css        تمام استایل‌ها و واکنش‌گرایی
assets/js/main.js           تعامل‌ها، چالش‌ها، ذرات و انیمیشن‌های کلیک
assets/images/              محل عکس‌ها برای مرحله‌ی بعد
pages/museum.html           فعلاً صفحه‌ی موقت موزه‌ی خاطرات

اجرا:
1) فایل ZIP را استخراج کن.
2) پوشه را در VS Code باز کن.
3) index.html را با Live Server اجرا کن؛ یا برای تست اولیه خود فایل را در مرورگر باز کن.
4) اسم فایل‌ها و مسیرهای بالا را تغییر نده مگر اینکه لینک‌ها را هم اصلاح کنی.

نکته:
فونت‌های آنلاین از Google Fonts بارگیری می‌شوند؛ بدون اینترنت، فونت جایگزین استفاده می‌شود.
موزه‌ی خاطرات هنوز نسخه‌ی موقت است و در مرحله‌ی جداگانه با شش عکس ۱۶:۹ تکمیل می‌شود.
